# Capturas do app — conta de demonstração

Todas tiradas na conta de demonstração (consultório do Freud), 1080×2137,
sem barra de status. O Designer usa pelo nome, no campo `captura` de um
quadro do tipo `captura`.

| Nome | Tela |
|---|---|
| `inicio-clinica` | Início, aba Clínica (Nova Sessão, Novo Registro, Clientes, Relatórios) |
| `inicio-financeiro` | Início, aba Financeiro (Entradas, Saídas, Cobrança, Fiscal) |
| `agenda-semanal` | Agenda, visão semanal com os horários fixos |
| `analisantes` | Lista de analisantes |
| `supervisionandos` | Lista de supervisionandos |
| `analisante-ficha` | Ficha do analisante: paralisação da análise, autorização de gravação |
| `analisante-detalhes` | Ficha: modalidade, horário, preço da sessão, dia de pagamento, indicação |
| `analisante-sessoes` | Histórico do analisante: sessão transcrita e sessões anotadas |
| `registro-sessao` | Um registro de sessão aberto |
| `registro-supervisao` | Um registro de supervisão aberto |
| `novo-registro` | Formulário de novo registro (data, título, importar texto via imagem) |
| `cobranca` | Cobrança: recebimentos previstos do mês, com WhatsApp e e-mail |
| `entradas` | Entradas, visão mensal: previsto, recebido, por analisante |
| `fiscal` | Fiscal: recibos/notas por analisante, automático e emitir |
| `perfil` | Meu Perfil: capa, foto e "Sua atividade" |
| `perfil-rubrica` | Meu Perfil: rubrica usada nos recibos e o plano |
| `perfil-indicacao` | Meu Perfil: indique e ganhe desconto |
| `perfil-contador` | Meu Perfil: créditos de IA e dados do contador |
| `perfil-exportar` | Meu Perfil: preferências e "Exportar meus dados" |

Todos os arquivos terminam em `-demonstracao.png`.
